# Figma / 구현 대조용 스크린샷

이 폴더에 **화면별 PNG**를 넣어 주세요. 파일명 예:

- `landing.png` — 랜ding (1277×2776 또는 iPhone 프레임)
- `main.png` — 메인 목록
- `detail-seopung.png` — 상세(서풍)

채팅에 이미지를 붙여 넣어도 됩니다.  
구현 시 margin **60**, gutter **20**, 8 column 기준으로 spacing·타이포를 맞춥니다.

**그리드 확인**: 브라우저에서 `?debug=grid` 를 URL 뒤에 붙이면 8컬럼 가이드가 표시됩니다.  
예: http://localhost:4321/main?debug=grid
